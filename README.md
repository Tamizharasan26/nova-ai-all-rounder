# NOVA AI — All-Rounder AI Agent

Mobile-first AI workspace with chat, agent routing, PDF/DOCX/TXT/CSV/image analysis, image generation, image editing, coding help, and browser voice input/output.

## Run
1. Install Node.js 18+.
2. Copy `.env.example` to `.env`.
3. Add `GEMINI_API_KEY`.
4. Run `npm install` then `npm start`.
5. Open http://localhost:3000.

## Render
Runtime: Node
Build Command: `npm install`
Start Command: `npm start`
Root Directory: blank
Branch: main
Add `GEMINI_API_KEY`, `GEMINI_TEXT_MODEL`, and `GEMINI_IMAGE_MODEL` as Environment Variables.

Never put API keys in public JavaScript or GitHub.
